# Hoops

My men's college basketball scores app.

- `app.html`: the whole app (layout, filters, ESPN feed). Edit this one.
- `build.py`: run `python3 build.py` after editing to rebuild `docs/index.html`.
- `docs/`: the files GitHub Pages hosts. Open the hosted link on your phone, then Share > Add to Home Screen (iPhone) or menu > Install app (Android).
- `relay/worker.js`: only needed if ESPN ever blocks the app from reading its feed directly.

Bracketology list lives near the top of the script in `app.html` (`BRACKET_FIELD`).
